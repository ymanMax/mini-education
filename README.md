# meow-education
基于微信小程序的在线教育平台，提供教师和学生双向匹配、课程发布、学习记录、互动交流等功能，满足用户多样化学习需求。

## 功能特性

### 教师功能
- **教师注册/登录**：支持教师用户注册和登录
- **个人信息管理**：支持教师完善和修改个人信息
- **课程发布**：支持教师发布课程信息，包括课程名称、描述、价格、时间等
- **学生管理**：支持教师查看和管理自己的学生
- **申请管理**：支持教师查看和处理学生的申请
- **收藏管理**：支持教师收藏感兴趣的学生

### 学生功能
- **学生注册/登录**：支持学生用户注册和登录
- **个人信息管理**：支持学生完善和修改个人信息
- **课程发布**：支持学生发布学习需求，包括学科、年级、学习时间等
- **教师管理**：支持学生查看和管理自己的教师
- **申请管理**：支持学生查看和处理教师的申请
- **收藏管理**：支持学生收藏感兴趣的教师

### 通用功能
- **用户匹配**：基于用户需求和信息进行智能匹配
- **搜索功能**：支持根据关键词搜索教师或学生
- **地图定位**：支持查看教师或学生的地理位置
- **投诉建议**：支持用户提交投诉和建议
- **帮助中心**：提供使用帮助和常见问题解答
- **关于我们**：展示平台的基本信息和联系方式

## 技术栈

- **开发框架**：微信小程序原生框架
- **数据请求**：封装了统一的API请求函数，支持mock数据
- **地图功能**：使用百度地图API实现地图定位和显示
- **UI设计**：使用微信小程序原生组件和WeUI样式库进行UI设计
- **全局状态管理**：使用微信小程序的globalData进行全局状态管理
- **工具函数**：封装了常用的工具函数，如日期处理、数据格式化等

## 使用方法

### 1. 环境准备

- 下载并安装微信开发者工具
- 注册微信小程序账号（可选，用于发布）
- 申请百度地图API密钥（用于地图功能）

### 2. 项目运行

- 克隆或下载本项目代码
- 打开微信开发者工具，导入本项目代码
- 在`/libs/bmap-wx.js`文件中配置百度地图API密钥
- 点击“编译”按钮，即可运行本项目

### 3. 项目配置

- **API接口配置**：在`/api/api.js`文件中配置API请求路径
- **Mock数据配置**：在`/api/mockApi.js`和`/utils/mockData.js`文件中配置Mock数据
- **全局样式配置**：在`/app.wxss`文件中配置全局样式
- **自定义组件配置**：在`/components/`文件夹中配置自定义组件

## 注意事项

- 本项目使用Mock数据进行开发，需要自行配置真实的API接口
- 地图功能需要申请百度地图API密钥，并在代码中进行配置
- 项目中使用了WeUI样式库，需要确保样式文件的正确引入
- 项目中包含多个自定义组件，需要根据实际需求进行使用和配置
